# Sentitito Bot 🤖💬

**Sentitito Bot** es un bot de Telegram diseñado para **analizar sentimientos y emociones** en mensajes enviados por el usuario.  
Forma parte del **Capstone Project** del programa **Samsung Innovation Campus (SIC)**.

---

##¿Qué hace?
- Recibe mensajes del usuario en Telegram
- Analiza el **tono emocional** y la **polaridad** (positivo / negativo / neutro)
- Devuelve una respuesta interpretando el estado del mensaje
- Registra datos para mejorar el análisis y estadísticas

---

## 🔧 Tecnologías utilizadas
| Tecnología | Uso |
|-----------|-----|
| **Python** | Lógica principal del bot |
| **Groq + LLaMA-3** | Modelo de lenguaje para análisis semántico |
| **MySQL** | Base de datos para almacenar mensajes y resultados |
| **Scripts shell/py** | Automatización y manejo interno |

---

## Requisitos
- Tener **Telegram** instalado en el teléfono o PC
- Tener conexión a internet
- Buscar en telegram "nombre que no me acuerdo" y escribirle
o usar el link de acceso directo

---

## Cómo usarlo
1. Abrí Telegram
2. Buscá **Sentitito Bot**
3. Iniciá el chat y mandale un mensaje
4. El bot te contesta y si lo deseas realiza un análisis de sentimiento en ese mensaje

---

## 🎯 Objetivo del proyecto
Con este proyecto buscamos:
- demostrar que las tecnologías de IA pueden acompañar a usuarios
- Integrar bot + IA + base de datos en un sistema funcional real
